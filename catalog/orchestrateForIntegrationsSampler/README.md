## Create Copy

1. Click the “Create Copy” button above.

2. To modify the orchestrations, open the app in the [Console](https://developer.workday.com/console/apps).

3. Click the name of the orchestration you want to review or modify to open Orchestration Builder.

4. You can use the [Debugger](https://forum.developer.workday.com/t/product-update-orchestrate-debugging-in-orchestrate/29232) to experiment with the orchestrations.

5. After making any changes, save them to App Hub.

6. If you are an Extend customer and would like to work out of a Dev tenant, deploy the app to your Dev tenant.

7. If you are not an Extend customer, or would prefer to work out of an Implementation or Sandbox tenant:

   Visit the App Overview, click the Promotions tab, and promote the app from Development to Implementation Release (for Implementation tenants) or Sandbox Release (for sandbox tenants). Then, install the app to the target tenant. _If you have an Implementation tenant available, we highly recommend you install it to the Implementation tenant first and test it there before moving to the Sandbox tenant._

# Usage Instructions

1. Open the app and navigate through the various orchestrations.

2. When you find an orchestration of interest, check [this forum post](https://forum.developer.workday.com/t/app-catalog-app-workday-orchestrate-sampler/36145) to learn more about it.
