# Workday Skill Router

## What it is

A markdown skill that tells an agent which other Workday skill to open. Use it when a task starts a new app or touches pages, models, and orchestrations together.

## What's inside

- `SKILL.md` is the skill: a decision table, the runtime choice, and the catalog folder layout.

## How to use it

1. Read `SKILL.md`.
2. Add that file to your agent using your platform's skill setup.
3. Ask the test questions at the bottom of `SKILL.md` and confirm the agent names the rule it is using.


## Before you deploy

This folder is markdown only. There is no app reference id, tenant host, secret, or worker id to replace. Do not add those values when you adapt the skill.
