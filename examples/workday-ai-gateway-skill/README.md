# Workday AI Gateway Skill

## What it is

A markdown skill that reviews an AI Gateway call or an AWS starter flow from the Workday catalog. It covers document intelligence, WQL generation, sentiment analysis, and the AWS starter apps.

## What's inside

- `SKILL.md` is the skill: Gateway and AWS call rules, plus the catalog apps to copy.

## How to use it

1. Read `SKILL.md`.
2. Add that file to your agent using your platform's skill setup.
3. Ask the test questions at the bottom of `SKILL.md` and confirm the agent names the rule it is using.


## Before you deploy

This folder is markdown only. There is no app reference id, tenant host, secret, or worker id to replace. Do not add those values when you adapt the skill.
