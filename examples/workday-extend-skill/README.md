# Workday Extend Skill

## What it is

A markdown skill that reviews or writes an Extend app shell and model. It checks AMD tasks, SMD authentication, business objects, security domains, and the app manifest.

## What's inside

- `SKILL.md` is the skill: shell, model, and security rules, plus the review output format.

## How to use it

1. Read `SKILL.md`.
2. Add that file to your agent using your platform's skill setup.
3. Ask the test questions at the bottom of `SKILL.md` and confirm the agent names the rule it is using.


## Before you deploy

This folder is markdown only. There is no app reference id, tenant host, secret, or worker id to replace. Do not add those values when you adapt the skill.
