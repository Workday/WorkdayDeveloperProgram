# Workday APIs Skill

## What it is

A markdown skill that picks Graph, WQL, REST, or SOAP and then reviews the call. It points at catalog samples for each protocol.

## What's inside

- `SKILL.md` is the skill: how to choose an API, and the rules for each call style.

## How to use it

1. Read `SKILL.md`.
2. Add that file to your agent using your platform's skill setup.
3. Ask the test questions at the bottom of `SKILL.md` and confirm the agent names the rule it is using.


## Before you deploy

This folder is markdown only. There is no app reference id, tenant host, secret, or worker id to replace. Do not add those values when you adapt the skill.
