# Workplace Adjustment & Accessibility Passport

## What it is

An Extend application and Workday Home Card that gives employees a confidential, portable **Workplace Adjustment Passport**. 

Employees with disabilities, neurodivergent work patterns, chronic medical conditions, or ergonomic requirements often face friction repeatedly disclosing and renegotiating their accommodations whenever they change teams, managers, or office locations. 

This solution records approved workplace adjustments (such as assistive software, ergonomic equipment, sensory focus hours, and communication preferences) into a secure custom business object. When an employee transfers, the new manager receives an executive briefing of active accommodations without disclosing sensitive diagnostic or medical records. Employees retain granular consent controls over what information is shared with managers versus kept solely with HR specialists.

## What's inside

- `appManifest.json`: Application metadata definition, reference ID, and version configuration.
- `cards/passportSpotlight.carddefinition`: Workday Home card definition providing 1-click status visibility and quick launch actions.
- `model/WorkplaceAdjustmentPassport.businessobject`: Custom business object schema storing employee references, adjustment categories, equipment specifications, review dates, and manager sharing consent.
- `model/PassportSecurityDomain.securitydomain`: Security domain configuring role-based page and data permissions.
- `model/AdjustmentPassportBP.businessprocess`: Business process definition routing new adjustment submissions for review and acknowledgment.
- `presentation/passport.amd`: Application Metadata Definition registering tasks and routing patterns for worker, request, and manager briefing views.
- `presentation/passport.smd`: Site Metadata Definition configuring authentication and localization.
- `presentation/myPassport.pmd`: Worker self-service landing page displaying active adjustments, privacy safeguards, and renewal timelines.
- `presentation/requestAdjustment.pmd`: Interactive form to record practical accommodations and manage consent.
- `presentation/teamBriefing.pmd`: Manager view summarizing approved team accommodations for smooth onboarding and team collaboration.
- `sample-data/sample-passport-entry.json`: Realistic, sanitized sample records illustrating assistive technology, ergonomic equipment, and flexible schedule entries.
- `example.json`: Metadata file powering the Workday Developer Program gallery.

## How to use it

1. Deploy the app source to your Workday Cloud Platform (WCP) development tenant using App Builder, the Workday CLI (WDCLI), or Local Disk Sync.
2. In your tenant, map `PassportSecurityDomain` to your target security groups (e.g., Employee Self-Service, Manager Self-Service, and HR Workplace Accommodations Partner).
3. Activate the `passportSpotlight` card in your tenant's Workday Home configuration under **Configure Workday Home**.
4. Launch the application from the Home card or the App Launcher to review active adjustments or submit a new workplace accommodation request.

## Before you deploy

Before deploying this example to your target tenant, verify the following configuration points:

- **App reference id**: `workplaceAdjustmentPassport` in `appManifest.json`, `presentation/passport.amd`, and `presentation/passport.smd` is the sample app reference ID. Replace it with the ID generated by your tenant during app creation, or access it dynamically using `site.applicationId` in PMD scripts.
- **Security domains**: Map `PassportSecurityDomain` in `model/PassportSecurityDomain.securitydomain` to your organization's appropriate security groups (e.g., All Workers for employee self-service view, and People Leaders / Managers for the team briefing view).
- **Base URLs**: All PMD endpoints utilize `baseUrlType: "workday-apps"` to resolve your tenant's API gateway without hardcoding tenant URLs or environments.
- **Business Process Routing**: In `model/AdjustmentPassportBP.businessprocess`, ensure the review step is assigned to your organization's designated HR Workplace Accommodations Partner security group.
