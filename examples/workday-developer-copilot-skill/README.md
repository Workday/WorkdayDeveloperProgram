# Workday Developer Copilot Skill

## What it is

A markdown skill that writes a prompt for the product Workday Developer Copilot. It names the artifact to generate and the data that must stay out of the prompt.

## What's inside

- `SKILL.md` is the skill: prompt contents and the privacy limits.

## How to use it

1. Read `SKILL.md`.
2. Add that file to your agent using your platform's skill setup.
3. Ask the test questions at the bottom of `SKILL.md` and confirm the agent names the rule it is using.


## Before you deploy

This folder is markdown only. There is no app reference id, tenant host, secret, or worker id to replace. Do not add those values when you adapt the skill.
